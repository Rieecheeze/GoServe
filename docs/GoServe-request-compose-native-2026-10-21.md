# Native request creation and evidence

The production office entry now opens a request form for ready Students. It reads actual office services, delivery choices, canonical quotes and workflow options; it never substitutes preview services or guessed fees. Purpose uses the existing optional notes field because the backend has no configured-purpose dropdown contract.

The user explicitly reviews and then submits. Required cash payment is never preselected. A lost submission response retains its intent/key and freezes edits for an identical retry. Success appears only after canonical reload. Account replacement clears private input and prevents stale publication. Expired quotes expose a real catalogue reload, and selected service text uses the canonical quote name.

Evidence selection reads one content-provider document locally before any prepare/upload request. Bounds come from the server policy, with an independently labelled device memory limit. Prepare retries keep the key; upload retries keep the prepared file and identical bytes. Only verified, current, correctly scoped metadata reaches the parent request. The optional JPEG camera uses a nonexported FileProvider exposing only cache/request-evidence, temporary read/write grants and an owned output deleted after local read/cancellation. Capture ownership survives Activity recreation. No broad media or storage permission was added.

SharedMotion supplies tactile feedback on form, dialog and dynamically added buttons: scale1 to0.97 over80ms on press, returning to1 over120ms on release. Disabled controls reset immediately; reduced-motion settings remove scaling. The brand loader is reused during quote/read/upload operations. No mascot was added to loading screens.
